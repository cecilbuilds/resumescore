# ResumeScore — Free ATS Resume Analyzer

Paste your resume. Get an instant ATS compatibility score with specific fixes across 6 categories.

**Live:** [https://cecilbuilds.github.io/resumescore/](https://cecilbuilds.github.io/resumescore/)

## Features

- **6-Category ATS Analysis:** Section Completeness, Action Verbs, Quantified Achievements, Keyword Optimization, Formatting & Structure, Readability
- **Instant Results** — No API calls, no loading, no waiting
- **100% Client-Side** — Your resume never leaves your browser
- **No Signup Required** — Zero friction, just paste and analyze
- **Actionable Suggestions** — Specific fixes for every issue found

## Privacy

ResumeScore runs entirely in your browser. Your resume text is never transmitted to any server. Zero cookies, zero tracking, zero data collection.

## Architecture

Single self-contained HTML file (47KB). No build system, no dependencies, no framework. Vanilla HTML + CSS + JavaScript deployed to GitHub Pages.
